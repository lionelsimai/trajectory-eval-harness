# Contributing

Thanks for contributing! Please:

1. Fork, branch from `main`, keep changes focused.
2. Run `ruff check src tests benchmarks` and `python -m pytest -q` — both must pass.
3. Add tests for behaviour changes; update `CHANGELOG.md`.
4. Open a PR using the pull request template; describe the problem, not just the fix.

No secrets in code or tests. Configuration goes through environment variables.
