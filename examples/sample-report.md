# Sample Eval Report

Generated by `traj-eval eval --data data/golden.jsonl` on the golden set.

```json
{
  "count": 120,
  "mean_score": 1.0,
  "pass_rate": 1.0,
  "worst": [
    {"id": "golden-search-book-000", "score": 1.0}
  ]
}
```

Interpretation: every hop (tool choice, arguments, state transition) and the
final answer/state scored perfectly on the golden trajectories. A regressed
agent run scores below the gate threshold (0.99) and `traj-eval gate` exits 1,
blocking the PR. See `benchmarks/bench_gate.py` for a deliberate-regression demo.
